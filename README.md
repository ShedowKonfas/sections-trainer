Интерактивный тренажёр по построению сечений куба и тетраэдра секущей плоскостью. Всё — один HTML-файл: геометрия, 3D-сцена, генератор задач и пошаговые объяснения.

## ✨ Возможности

- **Изучить** — ставишь три точки, получаешь секущую плоскость и сечение с пошаговым разбором методом следов.
- **Задачи** — случайные точки `M`, `N`, `K` на рёбрах; нужно отметить вершины сечения, проверка с допуском и счётчик правильных ответов.
- **Инструменты**: точки, линия по двум точкам, линия по грани, продление линии до рёбер (след), ластик, отмена линии и очистка.
- **Привязка** к рёбрам, граням, существующим точкам и пересечениям линий наброска.
- Подсветка граней, подписанные вершины, названия многоугольников и граней в объяснении.

## 🚀 Запуск

Открой `sections-trainer.html` двойным кликом в Chrome или Edge — сборка, npm и сервер не нужны.

```powershell
Start-Process 'D:\HTML\Section\sections-trainer.html'
```

three.js r160 загружается с `unpkg.com`, поэтому для работы нужен интернет. Офлайн-версии пока нет.

## 🎮 Управление

| Действие | Как делать |
|---|---|
| Вращать фигуру | зажать ЛКМ на пустом месте сцены и тянуть |
| Приблизить / отдалить | колесо мыши |
| Поставить точку | инструмент «Точки» → клик по ребру, грани или другой точке |
| Провести линию | инструмент «Линия» → два клика; включи «Продлевать линию» или «Линия по грани» для следа |
| Удалить точку | инструмент «Ластик» → клик по точке, либо кнопка «Убрать точку» в задачах |
| Очистить | «Убрать линию», «Очистить набросок» или «Очистить всё» (условие задачи сохраняется) |

## 🧠 Как устроено

Плоскость задаётся тремя точками; сечение считается как пересечение плоскости с рёбрами тела, вершины сортируются по углу вокруг центроида — так получается выпуклый многоугольник. Генератор задач делает до 800 попыток и отбрасывает вырожденные варианты. Объяснение строит след секущей плоскости на грани-основании, затем сторону за стороной добавляет рёбра сечения.

Весь код лежит в одном `<script type="module">`: THREE.js + OrbitControls через `importmap`, без бандлера и тестов.

## ⚠️ Ограничения

- Нужен доступ к `unpkg.com` (three.js с CDN).
- Снап к пересечениям считается в экранных пикселях (15 px) — при сильном зуме может захватывать лишнее.
- Точки без привязки к ребру объясняются координатами, а не названием ребра.

Идеи на будущее: офлайн-версия с локальным three.js, подписи у точек-пересечений, автоматическое построение сечения по нарисованным линиям.
